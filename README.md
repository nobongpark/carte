# 단체 식단표 생성기

**인원**과 **기간**만 넣으면 1일 3식(조식·중식·석식) + 밤 9시 간식 식단표와 재료량을 자동으로 만들어 주는 웹페이지입니다.

## 사용 방법

1. `index.html`을 열거나 GitHub Pages 주소로 접속합니다.
2. 인원과 기간(시작일 ~ 종료일)을 입력하고 **식단표 만들기**를 누릅니다.
3. 결과는 세 개의 탭으로 확인합니다.
   - **식단표**: 주차별 식단표. 메뉴 이름을 누르면 다른 메뉴로 바꿀 수 있습니다.
   - **조리지침서**: 날짜·끼니별로 메뉴마다 들어갈 재료와 양
   - **장보기 목록**: 기간 전체 또는 주차별로 재료를 합산한 발주용 목록
4. 각 탭은 엑셀(CSV)로 저장하거나 인쇄할 수 있습니다.

세부 설정에서 첫날 시작 끼니, 마지막 날 끝 끼니, 재료 여유분(기본 5%), 특식 데이 포함 여부를 바꿀 수 있습니다.

## 재료량 기준

- 72시간 공부캠프 **29기 조리지침서(300명 기준)** 의 메뉴별 재료량을 정리해 `js/data.js`에 넣었고, 입력한 인원에 비례해 계산합니다.
- 원본에 양이 없던 부재료(양파·대파·양념 등)와 밥·김치는 단체급식 표준량으로 추정했으며, 화면에서 흐린 글씨로 구분됩니다.
- 원본에서 단위 없이 숫자만 있던 채소·육류는 kg으로 해석했습니다.

## 식단 구성 원칙

| 끼니 | 구성 |
| --- | --- |
| 조식 | 주찬 + 백미밥 + 국 + 부찬 2 + 김치 + 씨리얼/모닝빵/죽 곁들임 |
| 중식 | 주찬 + 잡곡밥 + 국 + 부찬 2 + 김치 + 토핑 샐러드 (+ 이틀에 한 번 후식), 3일에 1번 일품요리 |
| 석식 | 주찬 + 백미밥 + 국 + 부찬 2 + 김치 + 샐러드 + 과일 |
| 간식 (21:00) | 간식 + 음료 |

- 같은 메뉴가 며칠 안에 반복되지 않게, 이어지는 끼니의 주재료(돼지·소·닭·생선 등)가 겹치지 않게 배치합니다.
- 특식 데이: 주 1회 석식(피자 → 치킨 → 고기파티 순), 주 1회 중식(분식 → 중식 순).

> 영양사가 검토한 식단이 아닙니다. 알레르기 등 제한 식단이 있으면 메뉴를 직접 바꿔 주세요.

## 메뉴 추가·수정

`js/data.js`의 각 목록에 한 줄씩 추가하면 됩니다. 재료는 `재료명 수량단위; 재료명 수량단위*` 형식이며(300명 기준), `*`는 추정값 표시입니다.
